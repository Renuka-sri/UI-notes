Display properties:- 
        -->it contains multiple values that are:- inline,block,inline block,none,flex,grid.
    html ele dived into 2 types 
                block level elements(strat at new lilne)
                inline elements(start in same line)
     --->Display properties are used to convert the inline elements into block level element and
         block level element  into inline elements.

        Display: block:- used to convert inline element into block level elements.
                ex:- span{
                                background-color: blanchedalmond;
                                color: black;
                                padding: 10px;
                                margin: 10px;
                                display: block;
                                width: 100px;
                                box-shadow: 4px 4px 4px black;
                                text-align: center;
                                border-radius: 10px;
                        }
        display: inline :- used to convert block level elements into inline elements.
                -->it does not support width property 
                ex:-         p{  background-color:aqua;
                                color: black;
                                padding: 10px;
                                margin: 10px;
                                display: inline;
                                box-shadow: 4px 4px 4px black;
                                text-align: center;
                                border-radius: 10px;}
        display: inline bock:- 
        display: none:- used to hide the content in the webpage.
        display:flex:- used to arrange the elements in rows or columns.
                --> this property always used in parent level.
